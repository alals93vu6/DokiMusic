# KeyScore · 樂曲轉按鍵

## 僅主旋律

在解析頁「旋律模式」選擇「僅主旋律 · 放棄和弦」，分析或重新套用後，再到編輯模式載入結果。會依原始音高、起音群組、強度、長音與前後音高連續性挑選單一聲部，再映射到遊戲音域；不單純取最高音，也不會在旋律結束後補回已丟棄的和弦尾音。保留原本「旋律與和弦」選项。

此功能是辨識音符之後的啟發式旋律選取，不是能準確區分主奏與伴奏的新 AI 模型。主旋律較弱、在低音部、快速交替或與伴奏相似時仍會選錯，需要人工修正。切換此選項沿用辨識快取，不重跑音源分離。編輯模式可自由加回音符，不受自動主旋律單音限制。

## v0.3 編輯模式

### 區塊選取與批次操作

從時間軸空白處按住滑鼠拖曳，框內相交的音符會一起選取。拖曳任一已選音符可整批改變時間與音高，或用下方「整批時間位移／音高位移」精確移動。框選狀態只允許移動與刪除：新增、單音修改、音高／起點／長度欄位停用，音符右緣縮放也停用。可按刪除按鈕或時間軸上的 Delete 批次刪除。

批次移動保留間距、強度與長度；超出時間或 15 鍵音域邊界時限制整組位移。每次移動或刪除可一次復原／重做。按「解除框選」、點擊空白或未選取音符恢復單音操作；時間尺仍用於播放游標。框選本身不改動樂譜。

編輯模式提供合成音試播 OFF／ON 開關。ON 時從目前位置播放，拖曳拉桿或紅色游標時改為約 0.1 秒的當下音符試聽，放開自動從新位置繼續；OFF 時靜音定位。曲末保持 ON 待命，可直接拖回重播。停止按鈕等同 OFF，保留目前位置；「回到開頭」回到 0 秒，ON 時立即重播。長音可從中途接續；這是編輯樂譜的合成音，不是原始 MP3，也不發送遊戲按鍵。編輯音符、復原／重做、切換頁面或頁面隱藏會關閉試播。游標位置僅供編輯試聽，匯出仍包含整首樂譜。

上方「編輯模式」可建立空白樂譜、載入已完成的解析結果，或匯入新版 KeyScore Python。
雙擊時間軸空白處新增音符；拖曳音符移動時間與音高，拖曳右緣延長／縮短。選取後可在下方精確修改按鍵、起點和長度，或刪除。提供復原、重做、時間縮放及 0.05／0.1／0.25 秒吸附。

編輯器處理遊戲 15 鍵的可演奏樂譜，保留前奏空白與手動時間；匯出不重新執行自動編排。相同按鍵重疊、同時超過 8 音、無音符或無效時間會阻止匯出並說明原因。離開編輯頁保留記憶體中的修改，關閉程式前請匯出保存。

匯出格式固定第 1 行 UTF-8 宣告、第 2 行 `# KEYSCORE_EDITABLE_SCORE_V1`、第 3 行 `# KEYSCORE_DATA: ` 後接 Base64 JSON。JSON 包含 version、title、settings、notes；每個音符含 s/e（秒）、k（按鍵）、p（顯示音高）、v（強度）。匯入會驗證內容，音高由按鍵及根音重建，不會執行 Python，也不解析任意程式邏輯。標記是格式識別，不是程式安全簽章；手改播放器其他行不會改變此樂譜資料。新匯出一律使用內建播放器模板。

舊版無標記 Python 不支援直接匯入；需重新解析原音訊再匯出新版。一般 Python 也不是可匯入的樂譜。

Windows WebView 桌面工具。匯入 MP3，在本機辨識音符並編排成遊戲可用的 15 個鍵，再儲存獨立 Python 演奏腳本。

## 使用

1. 雙擊桌面 `KeyScore.bat`。
2. 選鋼琴或大提琴；混音選「混合樂器，先分離目標」，清晰獨奏可選「純獨奏／原流程」。匯入音訊後按「分析並編排」。
3. 試聽合成音預覽，查看移八度與近似音數量，視需要調整設定並重新編排。
4. 按「下載 Python」選擇儲存位置。執行匯出的 `.py`，預設 5 秒內切回遊戲樂器介面。
5. 按住 Esc 或切換視窗會停止；程式在正常結束、取消或例外時會嘗試釋放所有由它按住的鍵。

## 已知音高與限制

- 從低到高：`A S D F G H J Q W E R T Y U I`。
- 尚未量測遊戲的絕對音高。預設最低音 C4，其後為大調音階兩個八度加頂音。可在「音高與音域校準」修改根音。
- 支援同時 1–8 音、獨立長短音、5/10/15 秒倒數、速度調整及 ±12 半音移調。
- 超出範圍會移八度；升降音可近似替換或略過。v0.2 新增 AudioSep 目標樂器分離，再交給原本 Basic Pitch 辨識。
- 鋼琴模式優先保留最高音、最低音，再填入較強和聲；大提琴模式優先保留較強音符，預設單音。
- 同一鍵的重疊音会合併或截短後重彈。發聲限制可能切斷或恢復聲部。這是可演奏編排，不是無損還原。
- Basic Pitch 是通用轉譜模型；清晰單一樂器比完整混音更合適。辨識錯誤、踏板與滑音細節可能影響結果。
- 音訊最長 20 分鐘、100 MB，採 30 秒分段辨識；分段邊緣的長音與起音可能有誤差。首次分析會有模型與 JIT 載入等待。
- 預覽只播放前 30 秒，使用瀏覽器合成音，不代表遊戲音色。匯出包含整首編排。
- 匯出腳本使用 Windows SendInput 掃描碼，不需第三方套件。它仍需要可用的 Windows Python（這台已有 3.13）。若遊戲以管理員身分執行，播放器須具備相容權限。
- Windows 事件排程不是硬即時系統。延遲超過 0.5 秒會停止，以免補發大量按鍵。

## 環境與檔案

此台電腦使用 Python 3.10 的專用虛擬環境執行分析，與原有 Python 3.13 共存。
應用程式來源在本資料夾。模型、暫存及紀錄在 `C:\Git\DokiMusic\work\keyscore`。
啟動器優先使用專案根目錄的 `.venv`；沿用其他環境時可用根目錄 `runtime-path.txt` 指定 pythonw.exe。也可雙擊本資料夾的 `KeyScore.bat`。
直接打開 `ui.html` 不會連接本機引擎；請使用啟動檔。

若需要在另一台 Windows 安裝：保持 `outputs/KeyScore` 和 `work/keyscore` 目錄結構，使用 Python 3.10 建立虛擬環境，安裝 `requirements.txt`，確認 Microsoft Edge WebView2 Runtime 已安裝，再執行 `app.py`。GPU 版 PyTorch 需另依顯卡安裝相容版本；本機使用 2.5.1+cu124。
分離模式還需要 `work/keyscore/models/audiosep` 中的兩個 safetensors 與 manifest。重建工具為 `work/keyscore/fetch_audiosep.py` 及 `prepare_audiosep.py`；先安裝 `transformers==4.46.3`，依序執行，首次需要網路及約 1.3 GB 原始權重。正常分析不需要網路。

## v0.2 分離模式

- 自動模式優先使用 GPU；亦可選 CPU。模型缺失或 GPU 記憶體不足會顯示錯誤，不會暗中改分析原混音。
- 標準與嚴格模式使用訊號證據門檻；嚴格模式可能漏掉較弱的目標音，分數並非機率或準確率。
- 鋼琴保留起音與和弦；大提琴加強諧波、降低競爭樂器訊號，並合併沒有新起音的同音長音片段。
- 控制測試中誤判減少，但三種樂器混合及樂器共用音高時仍可能保留伴奏。這版是可測試的改善，尚未達到可靠還原任意歌曲的程度。
- 16 組測試使用 SoundFont 合成演奏，不能代表真實錄音準確率。詳細數據見 `VALIDATION.md`。
- 變更樂器、分離模式、嚴格度或裝置會重新辨識；只修改速度或按鍵編排設定可沿用辨識快取。

技術來源：[Basic Pitch](https://github.com/spotify/basic-pitch)、[pywebview](https://pywebview.flowrl.com/)、[Windows SendInput](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput)。

## 多樂器編輯
- Ctrl+C／Ctrl+V 複製選取音符並貼到紅色游標；保留間距與長度。Ctrl+Z 復原，Ctrl+Y 或 Ctrl+Shift+Z 重做。輸入欄位保留原生文字快捷鍵。
- 新增樂器音軌後可分別匯入 Python 或建立音符。四種模式：鋼琴、大提琴、小提琴、豎琴；皆沿用原有鋼琴音高基準，試聽為合成音。
- 每軌可另外匯入比較組 Python。淡紫色背景音符不可修改，SWITCH 在同一播放位置切換目前音軌來源，其他音軌繼續播放。
- 左側喇叭切換該軌是否試聽；切換編輯音軌保留共同游標與各軌復原紀錄。
- 匯出只保存目前樂器的編輯組，預設檔名包含樂器；保留開頭休止。比較組與其他音軌不會打包，關閉前請逐軌匯出。
- 新增音色僅用於編輯器；音訊解析仍使用既有鋼琴／大提琴流程。多個輸出脚本的遊戲同步演奏需另行安排。

### 原始 MP3 參考音軌
編輯器樂器欄上方可匯入 MP3（50 MB、20 分鐘內），不會修改音訊解析來源或 PY 比較組。原曲與樂器共用試播時鐘、停止及定位；拖曳時原曲暫停，放開後同步繼續。音量與靜音可即時調整。正時間偏移略過原曲開頭，負偏移延後開始；例如解析裁掉 2 秒空白時可設 +2 秒。原曲不包含在 Python 匯出，關閉後需重新匯入。
