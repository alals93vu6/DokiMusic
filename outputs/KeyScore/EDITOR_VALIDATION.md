# 編輯模式驗證

區塊選取自動測試通過：矩形相交音符選取、實際 pointer handler 框選／批次拖曳／取消、整組時間與音域邊界限制、長度與間距保持、批次刪除／復原／重做、框選時鎖定單音控制、解除選取。播放與拖曳試聽回歸測試同時通過。此輪未新增原生視窗滑鼠實測。

OFF／ON 與拖曳試聽測試通過：OFF 定位不產生 AudioContext、ON 在游標處生成短音及和弦、50 ms 節流、放開時清理短音並恢復播放、切到 OFF 關閉全部音訊 context。拖曳試聽使用合成音，未量測真實音效延遲。

新增播放測試 `work/keyscore/test_editor_playback.cjs`：使用模擬 AudioContext 驗證指定起點、長音剩餘片段、和弦排程、重新定位、編輯停止、曲末停止及非同步 resume 取消競態，全部通過。前端 JavaScript 語法檢查通過。

WebView 實測：匯入 editor_ui_test.py，拖曳紅色游標至 2.50 秒（音符原為 2.00–3.50 秒），拉桿與秒數欄位同步；按試播後游標到達 3.50 秒並自動停止。未量測喇叭輸出音質，未發送遊戲按鍵。

v0.3 新增獨立編輯頁、Python 樂譜匯入與匯出。原解析與播放器保留。

## 自動驗證

`work/keyscore/test_score.py` 的 6 項測試通過：

- 固定行標記與樂譜往返，保留開頭空白及完整事件。
- 原分析結果匯出後還原事件不變。
- 匯入只讀取註解資料，即使其餘 Python 包含拋出例外的程式碼也不執行。
- 拒絕錯誤標記、版本、非有限數值、無效按鍵、過短音符及同鍵重疊。
- 拒絕超過 8 音的同時發聲。
- 新增、刪減與修改後的樂譜往返。

既有 `test_core.py` 6 項測試也通過，包含和弦獨立時長、同鍵重彈、匯出文字跳脫與播放器焦點切換清理。沒有發送真實遊戲按鍵。

## 格式與限制

僅支援含固定 V1 註解資料的新腳本，不能還原任意 Python 或舊版無標記檔案。編輯對象是遊戲 15 鍵樂譜，並非原始音訊各樂器分軌或傳統五線譜。關閉程式前需匯出保存；目前沒有磁碟自動儲存。編輯器使用秒為時間單位，未加入 BPM／拍號。
